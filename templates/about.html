Machine Learning Behind LaptopAI

Understanding the dataset, features and prediction model.

What is LaptopAI?

LaptopAI is a machine learning based laptop price prediction system. It uses laptop specifications such as processor, RAM, storage, display, graphics, operating system, warranty and rating to estimate the laptop price in Indian Rupees.

Dataset

The project uses a dataset containing 1,009 laptop records. The data is divided into training and testing sets to evaluate the performance of the machine learning model.

Machine Learning Model

LaptopAI uses a Gradient Boosting Regressor with a preprocessing pipeline. Feature engineering extracts useful numerical information from the original laptop specifications before the prediction model processes the data.

Engineered Features

Feature Engineering

The preprocessing pipeline extracts features including laptop brand, RAM in GB, storage in GB, display size, display resolution, pixels per inch, CPU cores and CPU threads. Categorical information is also processed using one-hot encoding.

Prediction Note

LaptopAI provides an estimated price based on the project's dataset and trained machine learning model. The result should not be considered a live market price, because actual prices can change depending on sellers, discounts, availability and market conditions.
